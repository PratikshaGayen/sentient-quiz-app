# Sentient Quiz App

A modern, interactive quiz application built with React that tests your knowledge about Sentient AI.

## Features

- **Interactive Quiz Interface**
- **Real-time Scoring**
- **Beautiful Design**
- **Responsive**


## Quiz Content

The quiz covers topics related to:
- Sentient Chat's multi-agent assistant
- Dobby model family
- Open Deep Search (ODS)
- Performance benchmarks and technical specifications
